# FF MAX Switcher (OneTapFiles v3)

Activate / Deactivate Free Fire MAX asset file with one tap (via Shizuku, works on Android 11+).

## Update your GitHub repo
1. Unzip this package.
2. Copy EVERYTHING inside the `OneTapFiles` folder over your repo (replace old files). Keep the hidden `.github` folder.
3. `git add -A && git commit -m "v3" && git push`
4. GitHub -> Actions -> "Build APK" -> open latest run -> download artifact **OneTapFiles-apk**.
5. Unzip it and install `app-debug.apk`.

Updates install over the old version (fixed signing key included), no need to uninstall.
